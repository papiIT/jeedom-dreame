# 01/11/2026 - 1.1.0

- Nouveaux réglages : puissance d'aspiration, débit d'eau, mode de nettoyage (aspiration, lavage, les deux), boost tapis, verrouillage enfant, ne pas déranger, volume.
- Prise en charge de l'encodage du mode de nettoyage des modèles à station de lavage et serpillières relevables.
- Nouvelle commande « Dernière mise à jour ».
- Dépendances installées par le cœur Jeedom (`packages.json`, environnement Python dédié) ; l'ancien environnement est supprimé à la mise à jour.
- Page Santé (dépendances, démon, robots).
- Catalogue des commandes dans `core/config/commands.json`.
- Traduction anglaise.
- Tests unitaires (Python et PHP) et intégration continue.

# 31/10/2026 - 1.0.0

- Première version : pilotage, état, station, consommables, réception temps réel.
